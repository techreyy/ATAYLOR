==========================================================
  CARA PASANG & JALANKAN DEMO A-TAYLOR (LAPTOP WINDOWS)
==========================================================

----------------------------------------------------------
LANGKAH 0 - PERSIAPAN (sekali saja)
----------------------------------------------------------
1. Pasang Git:
   https://git-scm.com/download/win
   (klik Next terus sampai selesai)

2. Pasang Node.js versi LTS:
   https://nodejs.org
   (klik Next terus sampai selesai)

3. Restart laptop (atau minimal tutup semua jendela
   Command Prompt / PowerShell) supaya Git & Node terbaca.


----------------------------------------------------------
LANGKAH 1 - DOWNLOAD (GIT CLONE)
----------------------------------------------------------
1. Buka Command Prompt (tekan tombol Windows, ketik "cmd", Enter).

2. Ketik perintah ini satu per satu, tekan Enter:

      cd C:\
      git clone https://github.com/techreyy/ATAYLOR.git

3. Hasilnya ada di folder:  C:\ATAYLOR

   PENTING: taruh di folder dengan nama sederhana seperti C:\ATAYLOR.
   JANGAN di folder yang path-nya ada huruf/simbol aneh, karena
   database (PostgreSQL) tidak bisa jalan di sana.

   Cara lain tanpa Git: buka https://github.com/techreyy/ATAYLOR
   -> tombol hijau "Code" -> "Download ZIP" -> ekstrak ke C:\ATAYLOR
   (pastikan isinya langsung SETUP-DEMO.bat dll, bukan folder di
   dalam folder).


----------------------------------------------------------
LANGKAH 2 - SETUP (sekali saja, BUTUH INTERNET)
----------------------------------------------------------
1. Buka folder C:\ATAYLOR di File Explorer.

2. Double-click:  SETUP-DEMO.bat

3. Tunggu kurang lebih 10-20 menit (mengunduh +-500 MB).
   Setup otomatis memasang:
   - PHP 8.3 + Composer
   - PostgreSQL 16 (database, port 5433)
   - semua library
   - database + data contoh
   - build tampilan web

4. Selesai kalau muncul "Press any key to continue" dan TIDAK
   ada tulisan merah. Tekan tombol apa saja untuk menutup.

   Kalau internet putus / ada tulisan merah:
   jalankan SETUP-DEMO.bat lagi. Bagian yang sudah selesai
   akan dilewati otomatis.


----------------------------------------------------------
LANGKAH 3 - JALANKAN SAAT PRESENTASI (TIDAK BUTUH INTERNET)
----------------------------------------------------------
1. Double-click:  JALANKAN-DEMO.bat

2. Akan terbuka beberapa jendela hitam (API, Scheduler, Web).
   JANGAN DITUTUP selama presentasi.

3. Browser otomatis membuka:  http://localhost:3000/login

4. Login dengan:
      Email    : admin@ataylor.demo   (Owner: owner@ataylor.demo)
      Password : ataylor123
   Tampilan bawaan = MODE FIKS (tanpa tombol "masuk cepat").
   Ingin tombol masuk cepat & ganti peran? Lihat "MODE FIKS /
   MODE DEMO" di bawah.

   Kalau halaman belum muncul / error, tunggu 5-10 detik
   lalu tekan F5.


----------------------------------------------------------
LANGKAH 4 - SETELAH PRESENTASI
----------------------------------------------------------
- Mengembalikan data ke kondisi awal (hapus semua hasil coba-coba):
  double-click  RESET-DATA-DEMO.bat  lalu login ulang.

- Mematikan demo: tutup semua jendela hitam tadi.

- Mau ambil versi terbaru dari GitHub:
  TUTUP dulu semua jendela hitam demo, lalu buka Command Prompt
  dan ketik:

      cd C:\ATAYLOR
      git pull

  lalu double-click JALANKAN-DEMO.bat. Bila ada kode tampilan
  yang baru, JALANKAN-DEMO otomatis membangun ulang tampilan web
  (sekali saja, 1-3 menit) dan memperbarui database.
  Bila muncul "[GAGAL] Ada library baru setelah git pull",
  jalankan SETUP-DEMO.bat dulu (butuh internet), lalu
  JALANKAN-DEMO.bat lagi.

- Mau memakai PERSIS versi presentasi (tidak ikut perubahan baru):
  buka Command Prompt, lalu ketik:

      cd C:\ATAYLOR
      git fetch --tags
      git checkout v1.1-presentasi

  lalu double-click JALANKAN-DEMO.bat.
  Kembali ke versi terbaru:  git checkout main  lalu  git pull


----------------------------------------------------------
KALAU ADA MASALAH
----------------------------------------------------------
- "Node.js belum terpasang"
    -> Pasang Node.js LTS, restart laptop, jalankan SETUP lagi.

- "Path folder berisi karakter khusus"
    -> Clone ulang ke C:\ATAYLOR.

- "Unduhan gagal atau checksum tidak cocok"
    -> Cek internet, jalankan SETUP lagi.

- Login gagal: "Tidak dapat terhubung ke server API"
    -> Artinya Laravel API tidak menyala. Tutup semua jendela hitam,
       jalankan JALANKAN-DEMO.bat lagi dan BACA pesan [GAGAL] yang
       muncul; di situ tertulis penyebab & solusinya, mis.:
       * SETUP belum selesai -> jalankan SETUP-DEMO.bat lagi.
       * PHP tidak bisa berjalan -> pasang Visual C++ Redistributable:
         https://aka.ms/vs/17/release/vc_redist.x64.exe
       * Port 8001 dipakai aplikasi lain (XAMPP/Laragon) -> tutup.
       * API tidak menyala -> foto jendela "A-Taylor API", kirim
         ke pengembang.
    -> Buka demo di laptop yang menjalankannya (localhost), bukan
       dari HP/laptop lain.

- "[GAGAL] Tampilan web gagal di-build"
    -> Tutup jendela hitam "A-Taylor Web" yang lama, lalu
       jalankan JALANKAN-DEMO.bat lagi. Masih gagal: jalankan
       SETUP-DEMO.bat.

- Tampilan masih versi lama setelah git pull
    -> Pastikan semua jendela hitam sudah ditutup sebelum
       JALANKAN-DEMO.bat, lalu tekan Ctrl+F5 di browser.

- Halaman tidak bisa dibuka / port 3000 atau 8001 sudah dipakai
    -> Tutup aplikasi lain yang memakai port itu, atau restart
       laptop, lalu jalankan JALANKAN-DEMO.bat lagi.


----------------------------------------------------------
MODE FIKS / MODE DEMO
----------------------------------------------------------
- MODE FIKS (bawaan, untuk presentasi): tanpa tombol masuk
  cepat akun demo, tanpa menu "Masuk sebagai"; modul yang belum
  tersambung data asli (Inventory, Chatbot, Platform) berlabel
  "Tahap berikutnya".
- MODE DEMO: tombol masuk cepat, menu ganti peran, label MOCK.

Cara ganti:
  1. Tutup semua jendela hitam demo.
  2. Double-click MODE-FIKS.bat  atau  MODE-DEMO.bat.
  3. Double-click JALANKAN-DEMO.bat (tampilan dibangun ulang
     otomatis, 1-3 menit, sekali saja).
